# CLAUDE.md

**Meadowfolk** — a cozy 3D farm-life game in a clay diorama, web-first, single-player and drop-in co-op as the same game. The design doc (`docs/2026-11-16-cozy-farm-game-design.md`) is the source of truth; this repo is its first public **slice** (§9.1) built on the existing Next.js + React Three Fiber stack (the owner chose to keep it rather than the doc's Vite/pnpm-monorepo/no-physics stack). Read the doc before adding gameplay.

## Non-negotiables (from the design)

- **No combat, ever** — no enemies, health, damage, durability or danger.
- **No grind** — nothing dies or is lost overnight; unwatered crops just wait; nothing punishes absence.
- **Every gold source is the town, every sink changes the world** (farm, villa, land).
- **One wallet per player**: gold and the personal bag live in the player's *profile*, never in the farm save.
- **Single-player is "host with zero guests."** All farm changes go through intents (`applyIntent`), even alone.
- **The host is the authority.** Guests send intents; the host's sim validates and broadcasts accepted ones; guests apply them to a read-only replica. The sim must stay deterministic (no randomness, no clocks inside `applyIntent`).
- **Guests** may water, harvest (into host storage), plant/feed from host storage, pet, deposit, ship, shop with their own gold, chat. They may **not** build, till, buy tiers/animals, withdraw from storage, spend host gold or end the day (`HOST_ONLY` in `sim.ts`).
- Clay-diorama look: chunky, rounded, matte, warm. Loading is a little scene, never a spinner.

## Commands

```bash
npm run dev | npm run build | npm run lint | npx tsc --noEmit
npm test                         # tsx --test src/game/sim/sim.test.ts
npm run relay                    # Colyseus relay on :2567 (relay/ has its own package.json)
cd relay && npx tsx smoke-test.ts   # with the relay running: host/guest message flow
```

`?debug` exposes `window.__meadow` (`teleport(x, z, face)`, `player()`, `session()`, `farm()`, `profile()`, `setTime(minute)` for DEV, `animals()` positions), `window.__meadowThree` (scene, camera; set `window.__meadowShot = { x, z, height, fov }` to hold the camera straight down for map renders) and `window.__meadowBackend`. `?profile=<name>` keeps a separate local profile (two players in one browser). A player named `DEV` is the **dev account**: infinite gold (`DEV_GOLD`, kept topped up by `addGold`, shown as ∞), shops open any time, and a DEV card under the clock to jump to 6 AM / 12 NN / 9 PM (`devSetTime`), freeze or unfreeze the clock (`devToggleFreeze`, `session.frozen`), grow every crop and planted tree at once (`devGrowAll` → `devGrow` intent) and ripen every fruit tree (`devRipenFruit` → `devFruit`); host only.

## Architecture

Next.js 16 (client-only game via `next/dynamic` ssr:false) · React 19 · React Three Fiber on three.js **WebGPURenderer** (WebGL2 fallback) · drei · Rapier · Zustand · Framer Motion · Tailwind v4 · Supabase (optional) · Colyseus relay. All 3D art is procedural clay except the rigged character GLBs; all sound is synthesized.

- `src/game/sim/` — **the farm simulation, pure TypeScript** (no React, three.js or browser APIs; could move to a server later). `types.ts` (FarmState, Tile, Crop, Placement, Animal, Intent, Effect), `content.ts` (crops, items, the clay kit `PIECES`, `PALETTE`, animals, shops + hours + lines, villa tiers, prices), `farm-map.ts` (the grid: `GRID` 45×20 one-metre tiles on the north bank, all owned, `tileCenter`/`tileAt`, ownership, villa footprint, orchard trees, footprints, `nearestEdge`), `sim.ts` (`createFarm`, `applyIntent` → effects, `endDay`, `placementProblem`, `migrateFarm`). **Trees** (`farm.trees`, `TREES` in content: apple, oak, pine) stand on single tiles — the orchard's old apple trees and wild ones come from `plantStartingTrees`; the axe (`chop` intent, host only, owned land) takes `TREE_HITS` chops by stage and drops the tree's wood (`woodItem`: apple trees give apple wood) and its seed; grown apple trees bear fruit (`TreeDef.fruit`, `fruitOn`): anyone picks it (`pick` intent — E at the tree, or using anything but the axe on it; a guest's goes to storage) and it grows back after `fruit.nights` nights in `endDay`; tree seeds (`ItemDef.tree`) are planted with `plant` (host only, needs a free ring round it) and grow a stage every `nightsPerStage` nights in `endDay`; `farm-trees.tsx` draws them, `sim.test.ts`. Every placed thing — villa walls, floors, fences, furniture, coops, the shipping bin — is one `Placement` record. Edge pieces (walls, fences) sit on a tile edge (`rot` 0 N, 1 E, 2 S, 3 W). Profile changes come back as `Effect`s addressed to a player; each client applies only its own.
- `src/game/state/` — no JSX. `director.ts` (**all gameplay rules outside the sim**: `submit` intents (host applies + broadcasts, guest pre-checks on a clone + sends), tools/hotbar, interact points, shops, the wall-clock day clock (pauses alone in menus/build mode, never with guests), sleeping + co-op countdown, thank-you tips, build mode with unlimited undo, saving, co-op handlers), `farm-store.ts` (the farm in the world — own or replica — mutated in place with a `rev` counter; `useClock` kept apart), `profile-store.ts` (persisted cache of the profile: id, name, look, gold, bag, nudges), `session-store.ts` (screen, panels, nearby, hotbar slot, target tile, build state, net status, chat, countdown, fade), `cloud.ts` (Supabase auth — anonymous first, attach email later —, farm/profile saves with a local cache where the newer copy wins, gifts), `settings-store.ts`.
- `src/game/net/coop.ts` — Colyseus client: host/join by 6-character code or `?join=CODE` link, message wiring, 10 Hz positions (`remotePositions`, read per frame), host-away detection.
- `relay/` — the thin Colyseus `FarmRoom` (`filterBy(['code'])`, max 4): authenticates (Supabase JWKS when `SUPABASE_URL` is set), records the host, forwards intents → host and deltas/snapshots/clock/countdown → guests, rate-limits, ends the session when the host leaves, 20 s reconnection grace. `maxPayload` is raised to 1 MB (a snapshot is tens of KB; Colyseus defaults to 4 KB).
- `supabase/schema.sql` — `profiles`, `farms` (one per owner), `farm_history` (trigger keeps the last 3), `gifts`, all under row-level security.
- `src/game/data/` — world data. `world-layout.ts` (town spots: `SHOP_SPOTS`, `CARPENTER_HOUSE`, the empty `GREEN_LOT`, setup shot), `terrain-plan.ts` (river, paths, plaza, bridge, pond, walkways, houses incl. the two-storey General Store, signposts, keep-clear zones), `ambient.ts` (villagers + the `WANDER` road network, with a spur to the tavern door; villagers stay in town, and the adults spend each evening in the tavern: `tavernVisit` gives each its own random time to go (6–7 PM) and to leave (8:45–10 PM), seeded by the day, so from about 8 to 8:45 PM everyone is in at once; Rosa and Bram (`TAVERN_PATRONS`, drawn by `TavernPatrons` in townsfolk.tsx) come too after closing and stand at the bar; and `TAVERN_SPOTS` where they stand inside; `villagers.tsx` walks them there and shows each only to players in the same zone), `looks.ts` (the character looks a player picks).
- `src/game/engine/` — no React. `input.ts` (keys → actions incl. `use`, `build`, `rotate`, `erase`, `undo`, `slot`, `chat`, `coop`), `sound.ts`/`music.ts` (synth), `world-state.ts` (per-frame player state, teleports, `animalPositions`, build-camera focus and pointer), `terrain.ts` (terrain masks/outlines/scatter; `onFarmGrid` keeps props off the farm; `groundHeight`).
- `src/components/world/` — R3F scene; components read state and call director functions, never decide outcomes. `farm-plot.tsx` (instanced soil and crops, the fence round the farm, the facing-tile cursor on the tile's own edges), `placements.tsx` (the clay kit pieces, their colliders (rebuilt only when the layout changes), the villa's auto roof over its walls which fades away — and walls drop to a cutaway — while you're inside or building, the build ghost, lantern glow at night), `animals.tsx` (hens wander by their coop; eggs at the door), `townsfolk.tsx` (Rosa and Bram behind their counters inside during opening hours; remote players, shown only when in the same zone as you), `shop-interiors.tsx` (the General Store, Carpenter and tavern rooms), `pointer-controller.tsx` (build-mode picking; click to use a tool while playing), `world-canvas.tsx` (day/night lighting updated in place), plus the town: `plaza.tsx` (the fountain at `LANDMARKS.fountain`, paving, lamp posts by the `BENCHES`), `terrain.tsx`, `scenery.tsx`, `landmarks.tsx`, `cottage.tsx` (`TiledRoof`), `farm.tsx` (the town's vineyard: grapevine rows on trellises (`VINE_ROWS`), scarecrow, tractor, and the barrels by the vineyard house, `HOUSES[2]`), `tavern.tsx` (the tavern on the old empty lot beside the tractor, `TAVERN`, kept out of `HOUSES` so the scatter doesn't move), `villagers.tsx`, `wildlife.tsx`, `post-effects.tsx`.
- `src/components/hud/` — `top-bar.tsx` (clock, date, gold, minimap), `farm-hud.tsx` (hotbar, build palette, toasts, banners, fade, chat/emotes), `panels.tsx` (shop, storage, shipping bin, coop, bag — where the player arranges their hotbar: drag or tap tools, seeds and fertilizer into its nine slots, saved as `hotbar` in the profile; unset, it fills itself (`hotbarKeys`/`setHotbarSlot` in the director) —, morning, thank-you, play together, account, help, pause), `controls.tsx` (interact prompt, touch joystick + USE).
- `src/components/screens/` — title (the Meadowfolk logo, `public/images/meadowfolk-logo.png`; behind it the world shows your saved farm, or a fresh one, via `showTitleFarm` in the director — scenery only, replaced on entering; "Join a Friend" when opened from a join link), setup (look + name), loading, options. `game-shell.tsx` — screen flow (`loading → title → setup → entering → play`) and keys → director.

## The world

One connected diorama laid out from the owner's map (see the diagram at the top of `terrain-plan.ts`). West column: the **farm** on the north bank. Between it and the river the strip is laid out by hand from the owner's plan (`FARM_FRONT`): a block of forest west of the road up from the bridge, and east of it a path (z ≈ −19.8) between two tree lines that, past the farm, steps up north-east through the forest to the statue's clearing, meeting the road from the town hall just below the statue. The farm is fenced all round (`FarmFence` in farm-plot.tsx) with its gate (`FARM_FRONT.gate`) where the road from the bridge arrives (the old ridge and the path off the farm's east edge are gone — the latter is in `RETIRED_PATHS`, kept in its old slot so the town's lanterns don't move) — all of it the owner's from the start (there is no land to buy; the orchard's old apple trees stand at its west end, and a pond — the `pond` kit piece at `POND_TILE`, given to older saves in v12 where there's room — lies in its north-east corner behind the house; that corner is a fenced chicken yard, `CHICKEN_YARD`, its fence ordinary fence pieces given to older saves in v13, and buying a chicken shed (the `coop` kit) at the Carpenter's has Bram build it straight away at `COOP_TILE` beside the pond — `buildCoopByPond` in the director, along with a `fence-gate` in the yard's gap (people walk through gates, which swing open; yards with a shed get one in v14) — or, if that spot is taken, it waits in the bag; hens roam wherever `animalCanWalk` lets them — inside the farm, through no fence, gate or wall, onto no solid piece but a pond — and now and then swim in the pond, floating low (`inPondWater`)), 45×20 tiles since v10, when it grew 4 rows north (`ROWS_ADDED_NORTH`: `migrateFarm` moves older saves' rows down first, the same ground) — then the river and bridge, the **town** round the origin (plaza with the fountain, General Store north-west, Carpenter east, cottages, pond, the tavern, and the vineyard with its house south-west by the field road), and the **beach**. The river turns south at x ≈ 27 to the **ocean**, splitting off the east column: the **forest** (with the statue, `STATUE`, in a clearing; reached from the farm's east edge or north from the town hall), the **town hall** (`TOWN_HALL`, last of `HOUSES`; sign, clock tower and flag in `east-side.tsx`) in the corner just over the bridge, facing the road, and the **playground** (`PLAYGROUND`) and woods (`FORESTS`) further east, and the east beach. Bridges cross to the town hall and between the beaches. `WORLD_BOUNDS` is asymmetric (west/east/north/south); the beach (`beachEdge`, `shoreAt`, `isBeach` in terrain.ts) is its own sand slab, and a wall at the waterline keeps you out of the sea. Each east region scatters from its own seed. The house is **bigger inside than out**, like a building in town: on the farm stands its closed shell (`houseShell` = the tier's `ext`, 7×5 at row 1 for tier 1, at the top of the farm (moved up from row 5 in v11) (the Carpenter's size; odd widths keep the door on the gate's column and the single path); row 0 behind it is where the back door opens), drawn by `HouseShell` in `placements.tsx` with the town `Cottage` (the Carpenter's look: brick base, arched door, farm-name plaque) and not made of placements. Its rooms are their own space off the map (`HOUSE_AREA`, grid columns 160–185, with their own ground collider), where the villa tiers' footprints (18×9 for tier 1) and all villa walls and furniture live; the same tile maths applies there, `inHouseArea` tells them apart. Going through a shell door jumps into the matching doorway inside (`houseEntry`), and a front door inside leads back out (`houseExit`). The starter rooms follow the owner's floor plan (`buildStarterHouse` in `sim.ts`): a 9×9 kitchen/living room and a 9×9 bedroom with double front/back doors and a wide doorway between. Indoors the walls facing the camera become one solid low wall and front doors are glowing openings. Pieces flagged `outdoor` stay on the farm; `villa`/`indoor` ones stay inside. The **shops** work the same way: their doors (`SHOP_SPOTS.counter`) lead into rooms of their own (`SHOP_ROOMS` / `shopRoom` in `world-layout.ts`, far east past the house's rooms) where you shop at the counter; closed shops stay locked (except for DEV). The **tavern** is one of them too (`tavern` in `SHOP_SPOTS`/`SHOP_ROOMS`/`SHOPS`, open 11 AM till the day ends) but sells nothing: its `SHOPS` entry has `chat: true`, so the bar is for a chat with Tess (`chatWith` in the director) — gold stays earned and spent where the design says. `zoneAt` (`state/zones.ts`) says which space a point is in (`out`, `house` or a shop id): the camera frames that room and remote players show only in your zone. Older saves are rebuilt by `migrateFarm` (starter furniture moves in; anything else in the way goes to storage as kit). The town's props are scattered from a frozen core box — append to the terrain-plan lists, don't insert, so nothing in town moves. A path added later goes in `LATE_PATHS` too: props are scattered as if it weren't there and then cleared off it, so nothing else moves (the scatter likewise still lays out against the old ridge, `wasRim`, and drops the ridge's own trees). Signposts thin out scattered trees within 2.6 m inside the scatter itself, so moving one near the town box shifts the town; verify with a before/after fingerprint of `getTerrain().scatter`.

## Gotchas

- WebGPU: no GLSL `ShaderMaterial`s (so no drei Sparkles/Environment/postprocessing) — use standard/node materials and TSL; create materials `transparent` up front instead of toggling it; never change a light's or the fog's constructor `args` or tree position (a new light id recompiles every material) — update properties in place (the day/night cycle does). Keep `bevelOffset: 0` on terrain extrusions. The AO pre-pass must be single-sampled.
- Physics uses `timeStep="vary"` so camera and bodies stay in sync on high-refresh displays.
- The farm is mutated in place: after any change call `useFarm.getState().bump()` (the director does) or the scene won't update. Never mutate it from a component.
- Rejected intents must not change state (the guest replica never sees them) — keep `applyIntent`'s failure paths pure and `credit()` help only on success.
- Hooks lint: director functions must not start with `use` (hence `applyTool`).

## Characters

Character models are rigged GLBs sharing one skeleton and five clips (Idle, Lookaround, Talk, Walk, Run); `character-model.tsx` plays them with crossfades and hides the outline shell. Looks: `mika.glb` (Farmer), `dr-fe-chibi.glb` (Scholar), `sarah.glb` (Student), `villager-*.glb`, and the plain `base-character.glb`. They're built in Blender by `scripts/build-pack-villager.py` (from micaelsampaio's "Low Poly Characters (PACK)") and `scripts/build-base-character.py` (mazko's chibi base model); shared steps live in `scripts/chibi_body.py` and `scripts/character_clips.py`.
